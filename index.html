Nothing leaves this page. The image is resized to 32×32, normalised with the CIFAR‑10 constants, and fed to the two graphs in your browser tab. The instrument was trained on 32×32 thumbnails of real objects, so a photograph of your cat at arm's length is outside its station — which is exactly what the decline line is for.

One difference from the register you should know about: a reference specimen reaches this page as an 8‑bit PNG, so the plate re‑reads it one quantisation step away from the float tensors the report tables used. Run against identical inputs, the two implementations agree to every digit shown here — on test_00284 both give confidence 0.96273, total evidence 3185.8 and τ 5.922 — while the register's float values for the same image read 0.95933 and 3051.6. Class decisions never differ; evidence sums, which pass through an exponential, can move a few percent.

What you are looking at

The live half of the CISC3024 AI Assignment 2 web component. The two graphs are the trained networks exported by src/export_onnx.py; the Dirichlet moments, temperature scaling, Dirichlet scaling and Laplace weight draws are recomputed in bench.js from data/instruments.json, with the same formulas the Python uses. webapp/model/verification.json records the parity check between the two implementations.

If the instruments will not load

Browsers refuse to fetch a 59 MB model from a file:// page. Serve the folder instead: from the project root run python -m http.server 8801 --directory webapp and open http://127.0.0.1:8801/. The measurement register needs no server and opens from disk.

Measured, not simulated

Every probability shown here comes from weights trained on 47 500 images with a 2 500‑image validation split, evaluated once on 10 000 test images. The decline line is the total uncertainty at which the test risk‑coverage curve passes 5 % risk — the same curve printed in register entry III.
