CIFAR‑10, reduced two ways

Observation register · measurements

A flexible evidential network (F‑EDL) and an identity‑curvature Laplace approximation (ICLA) trained on the same frozen split as a spectral‑normalised cross‑entropy baseline, then read against their own predictive posteriors. This register is the experiment's own output: every figure below comes from the files listed in the colophon, produced by the code linked there, with no number re‑entered by hand.
